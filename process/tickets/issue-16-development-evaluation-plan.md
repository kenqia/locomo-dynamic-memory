## What to build

使用者从固定官方原始数据生成并检查开发集评测计划，在公开 API 和现有页面查看划分、问题身份、策略与计划数量，确认将要运行哪些项目。这个预览不调用生成模型，不要求提前构建所有对话，也不执行本地测试集。

父规格用户故事：US1、US2、US3、US4、US12、US15、US16、US36。

## Acceptance criteria

- [ ] 开发集固定为 conv-26、conv-30、conv-41、conv-42，本地测试固定为 conv-43、conv-44；显式显示本地测试与隐藏评分集的区别，替换仍声称必须等待教师给出全部六个 ID 的当前提示。
- [ ] 复用官方数据校验、独立评测输入和既有划分约定，保留数据版本、来源与 artifact 身份；不改写官方原件或将 QA 答案、evidence、辅助摘要送入构建与查询。
- [ ] 通过公开入口生成开发集全量计划，原始 QA 顺序和重复问题均被保留，以对话及原始题目位置稳定定位每项；真实数据预览得到 757 题、四策略、3,028 个组合。
- [ ] 可预览 conv-26 的小规模计划，按 QA 原始顺序为类别 1–5 各取首题，共五题、20 个组合；缺少必要类别时明确拒绝，不能根据模型成绩换题。
- [ ] API 及页面能检查或导出划分、计划身份、策略和数量；规划阶段不要求完整 BuildVersion，执行前的版本固定由运行票完成。
- [ ] 开发计划入口只选开发对话，不触发本地测试问题生成；导入完整官方原件和读取元信息允许，不能把它记为测试成绩。
- [ ] 公开 API 行为测试验证划分、稳定问题身份、预览数量、QA 隔离及预览不调用外部模型；默认检查不下载模型、不付费。
- [ ] 同步相关使用说明，说明预览不代表已完成模型评测，不扩大为通用划分管理框架。
