已确认的方案

对话中的重要事实和事件提取为结构化 Memory，保留人物、时间和来源证据。旧 Memory 不因状态变化被直接删除，后续信息与历史记录之间维护 UPDATE、SUPERSEDE 等关系，并另外维护 Current State。

检索采用 Hybrid Retrieval，结合 BM25 关键词检索、Vector 相似度检索及 Entity/Time 结构化条件，寻找相关记忆。检索后根据问题、时间条件和历史状态关系选择有效记忆，再生成答案。

主流程如下：

Dialogue → Memory Extraction → Structured Memory / History / Current State
Question → Hybrid Retrieval → Relevant Memories → State Resolution → Effective Memory → Answer

M2 通过一张总体架构图和一张 Memory Recording / Retrieval 流程图讲清方法、流程与实现可行性。数据库、接口、Prompt 和具体代码模块在后续阶段细化。图片中的 Temporal Graph 等扩展不自动成为本轮承诺。
