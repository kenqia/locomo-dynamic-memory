## 内容修订

初稿已有愿景、范围、功能、评测和候选路线，本次在其基础上明确全组已确认的宏观方法：

- 结构化 Memory 保留人物、时间和来源，旧记录不因更新而直接删除。
- Current State 描述当前状态，历史问题继续按问题时间选择证据。
- Hybrid Retrieval 结合 BM25、Vector 和 Entity/Time 条件，检索后再判断状态。
- 大模型辅助抽取与理解语义，规则核查来源、字段和明确时间；不确定性保留。
- 对当前、历史、未消解冲突及证据不足给出可检查的场景。
- 两张宏观图替换包含详细字段及候选扩展的完整版图。
- 更新为已确认实名职责，按 M1 约定采用三轮迭代和缓冲；删除四人资格仍待确认的过时条目。
- 保留课程指标与对照计划，不写未经运行的效果或数字目标。

初稿中的数据库、完整接口和 Prompt 仍未定型，本轮不把它们升级为固定实现承诺。首版扩展仍独立于必做链路。
