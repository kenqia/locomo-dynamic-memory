## 失败原因

49 个失败项全部来自 Dynamic：35 项 `physical_request_policy_rejected`、14 项 `complete_resolution_input_budget_exceeded`。普通题失败 39 项，诊断题失败 10 项。前者受到本阶段批准的 160,000 字节 messages 上限限制；后者受到既有完整 resolve 输入 token 预算限制。两个最早的字节拒绝已按保存 Trace 离线重建，首次消息分别为 177,571 和 161,788 字节，均未发送 resolve 请求。

没有更改输入上限、截断证据、切换策略或追加失败补跑。已发生的 analysis 请求仍计入物理请求及成本。失败作为实际实验结果保留；不能把预算拒绝描述为模型语义错误，也不能因成功子集分数较高而删除这些失败。
