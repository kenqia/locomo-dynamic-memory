# Level C 答案来源审阅协议

本协议覆盖固定的 80 道普通题和 20 道诊断题、Hybrid 与 Dynamic 共 200 项结果。所有计划项均纳入，包括运行失败；不按得分、成功状态或答案内容选样。协议在真实生成期间形成，已观察到运行状态，尚未读取本轮 Gold 或审阅答案，因此属于探索性审阅流程。

## 输入与独立性

准备工具先核对全部 200 项的生成冻结、问题身份和文件 SHA，然后读取独立开发数据库中的四段完整 Source Turn 文本。审阅包只包含问题、运行结果、最终答案与解释、答案引用，以及按对话共享的原始来源。它不提供策略名称、官方得分、Gold、历史预测、resolver 选择或关系预测。

每项使用稳定的匿名 unit ID。私有映射保存 unit ID、问题、策略、对话和普通／诊断分层的关系；审阅者不得打开该映射或官方评分文件。两臂答案可能因文字风格透露策略差异，匿名包不能保证完全盲法。

审阅者记录身份、provenance、`review_kind` 和独立于生成实现的声明。AI 辅助独立审阅不属于人工或教师真值，也不提供双人一致性保证。工具仅验证结构、身份和逐字引文；语义结论由审阅者负责。

## 审阅方法

先通读分配对话的来源，再逐项核对问题所指的人物、事件、时间和条件。仅把来源明确支持的事实作为依据；保持计划与事实、历史与当前状态、共同参与与同名事件的区别。来源不足时记录 `undetermined`，不得根据常识补足答案。

核对直接答案及 explanation 中的全部事实性陈述。对于多项问题，检查同一人物、时间和语境下明确支持的全部项目；相关背景不自动构成回答，计划不自动构成已参与的活动。来源只能支持部分内容时，保留部分可回答的性质，不因为缺少全部答案而认定完全不可回答。

逐项记录以下标签：

| 字段 | 判断范围 |
| --- | --- |
| `answer_kind` | 实质回答、整体拒答、运行失败或无法判定；部分回答属于实质回答 |
| `source_support` | 直接答案和解释的事实陈述是否全部受原始来源支持；存在不受来源支持的事实陈述时记 unsupported，不能明确判断则记 undetermined |
| `citation_support` | 答案实际引用的来源是否支持相应陈述；不能用未被引用的来源补成引用正确 |
| `abstention` | 仅对整体拒答判断 correct、false 或 undetermined；实质回答用 not_applicable |
| `wrong_person` | 是否把另一人物的信息用于所问人物 |
| `wrong_event` | 是否混淆不同事件，或把计划当成已发生事实 |
| `wrong_time` | 是否错误归属时间、把报告时间当事件时间，或超出来源推断持续有效 |
| `list_omission` | 是否遗漏来源明确支持且问题要求的列表项目 |

四种错误使用 `true`、`false` 或 `null`。`false` 表示实际检查后未发现该错误，`null` 表示不适用或无法判断。运行失败没有模型答案，语义支持和拒答记 not_applicable，四种错误记 null；单独保留运行失败计数。

整体拒答只有在完整对话已检查、仍没有任一所问部分的支持证据时才能记 correct，并记录证据缺口。若来源能支持所问内容却整体拒答，记 false 并引用支持原文。拒答字面上命中官方类别 5 的评分规则，不自动证明拒答正确。

每个明确的支持、反证、错误 true 和 false abstention 判断保留同一对话内的 Source ID、连续逐字引文、用途和理由。引用只能证明定位和可追溯性；例如引用一段相似活动仍不足以证明所问时间或人物一致。对“未出现”之类缺口判断说明全文检查范围与最近相关上下文，不伪造不存在的反证。

## 验证与汇总

验证工具核对生成冻结、包、来源和私有映射的 SHA，拒绝重复或跨对话单位、非逐字引用和缺失身份。validate 可以把原样 null 模板记录为未审；最终 score 拒绝未审模板，要求全部 200 项都有明确审阅记录；失败项也需要记录其不适用性质。

普通题和诊断题分别报告，并按策略和对话分组。保留计划数、已审数、失败数、无法判断数和每项指标的可判断分母。来源支持率使用 `supported / (supported + unsupported)`；错误率使用 `true / (true + false)`。Unknown、未审、失败和不适用项分别报告，不暗中计为正确或错误。

官方 QA F1 与本审阅独立计算；官方评分只在全部回答冻结后读取开发 Gold。公开工件只保存数值、匿名 ID 和标签，完整原文、答案和审阅引文保留在 Git 忽略的私有目录。
