更新日期：2026-10-04。状态：初版整理，依据组长提供的教师答复、课堂记录和同学交流，并对照课程课件。没有独立核验课程平台通知或论文全文；本文不替代原始课件。

## 1. 项目是什么

课程项目是智能体动态记忆管理。输入为长期、多会话对话，系统提取结构化记忆，在收到问题后检索相关历史，判断保留、更新或替代关系，再根据问题与时间条件选择有效记忆并回答。Web 需要展示记忆、原始证据和状态解析，支持统一 JSON 导出。

只做相似度检索再调用模型，不能完整覆盖课件要求。图记忆、多跳、自适应检索和复杂冲突消解可作为扩展，不是首版必须承诺的功能。

- 私有 GitHub 仓库、成员访问权限、提交约定、从最初草稿起的版本记录，以及仓库 `process/` 目录。

- 使用课程选定的 6 段 LoCoMo 对话，4 段开发、2 段独立测试。其余 4 段可作扩展评测。
- 结构化记忆至少有内容、时间、会话或轮次来源，支持导出和 Web 可视化。

- 指标为回答 F1、证据检索 Recall@K、动态状态更新判断准确率。
- 对照方法包括 Full Text 和不做状态判断的 Vector RAG。
- 交付包含可运行 Web、完整代码、结构化 JSON、实验结果与对照分析、报告和展示。

## 6. 实现线索，不是定案

课堂记录提出先处理对话并存储，再根据问题检索，把证据和问题交给模型生成答案。结构化表示可以记录人物、事件、时间、地点等；检索可考虑关键词、相似度或组合策略。查询拆解和图结构是候选方法。

课件介绍 DimMem 的结构化维度与混合检索、MRAgent 的图结构与主动检索作为参考路线。团队尚未核验论文全文，也未承诺复现。技术选型需先核对版本、依赖、许可和课程限制。

检索条数不是越多越好，也不能仅凭直觉设定。开发集实验应检查遗漏证据、无关证据、时间条件和状态选择的影响。QA 标准答案只用于评价，不作为检索记忆来源；独立测试集不用于调参，这是团队当前建议的数据纪律。
