# ADR 0003：独立、默认关闭的 Temporal/Event Sidecar

日期：2026-11-03。状态：Proposed，待负责人确认与非作者真实成员复核。

## 问题与决策
原记忆检索需要解释事件时间、当前/历史状态以及证据不足，但本轮不能改动生产默认行为或使用付费实验。选择独立的、确定性规则驱动的 diagnostic_only Sidecar。它读取已冻结的导出/结构化输入，单独返回诊断，不覆盖原答案、证据或数据库。

默认关闭；显式 enabled=True 才运行。关闭时研究包装器直接返回原响应引用，不校验诊断输入、不执行规则。开启失败时保留原响应，另报 diagnostic_failed。撤销开启即可回到原行为，离线输出文件可单独删除。

## 选择与替代方案
| 方案 | 决策依据 |
| --- | --- |
| 独立诊断 Sidecar | 本轮采用；容易验证原数据不变，支持独立移除 |
| 修改生产关系/全局 Current State | 不采用；会影响现有答案与历史查询语义 |
| 模型判断全部事件关系 | 本轮不采用；没有授权新增付费模型实验，输出不确定 |
| 数据库迁移或永久写回 | 不采用；超出当前候选范围 |

## 语义约束
reported_at 是陈述时间，event_time 是事件有效时间，两者不可互换。计划不证明完成，否定必须有直接来源，无记录不等于未发生。缺少锚点保留 unknown。替代关系保留旧记忆；历史查询不改写全局状态。同事件需要明确的共同事件证据，不能仅凭主题相似合并。冲突保留竞争事实与来源，证据不足不能伪装成冲突或确定答案。

## 后果与限制
收益：可复现、可独立关闭、不增加模型调用。代价：规则仅覆盖明确英语表达与有限状态维度，不能代表通用时间理解。当前没有生产默认接入，没有真实问答质量增益结论。两份合成完整 Build 兼容检查不能替代两个合法真实历史 Build 的检查。

## 生效条件
负责人确认语义；真实成员复核；核对目标分支和实际基准 SHA。满足这些条件前本 ADR 仍为候选。批准人、日期和 PR 链接待实际发生后补填。
