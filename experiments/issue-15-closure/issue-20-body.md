## What to build

使用者通过可复现的本地入口检查真实运行条件，在隔离实验环境先验证 MiniLM 和 DeepSeek，再完整构建 conv-26，执行固定五题、四策略的真实预检，保存可读取和恢复的实验记录。

父规格用户故事：US5、US6、US7、US8、US9、US10、US11、US12、US13、US14、US48、US50、US51。

## Acceptance criteria

- [ ] 优先复用公开 API 与现有项目工具，入口可检查划分、环境、数据和模型条件，页面或 API 可读取产生的 Run 与结果，不另造业务实现。
- [ ] 仅检查凭据存在性，不打印、复制或把凭据写入仓库、快照、日志、导出或聊天；缺凭据时完成离线准备并明确报告阻塞，不用测试替身冒充真实调用。
- [ ] Embedding 仅通过既有锁定 extra 安装在项目独立环境，核实固定 MiniLM revision 的真实加载、384 维编码及超长拒绝；缓存目录存在不直接算验证通过。
- [ ] 首次真实请求前核对官方服务契约，沿用官方直连 deepseek-flash、关闭思考、JSON、校验与有限重试；记录核对日期、请求与返回模型身份及适用生成设置。
- [ ] 先运行既有 opt-in 的小型真实抽取和来源检查，再构建并发布 conv-26 的完整版本；保留抽取、索引、关系、投影各阶段进度和失败。
- [ ] 使用开发计划已确定的类别 1–5 各首题，运行五题、20 个组合，检查完整全文、版本固定、来源引用、逐项保存、报告与显式恢复行为，不设质量分数门槛。
- [ ] 受控回归、真实 MiniLM、真实 DeepSeek 抽取及真实 conv-26 全链路的执行状态分别留档；预检失败保留安全错误和已完成范围，未通过前不进入全量。
- [ ] 实验使用独立数据库和产物目录，保留旧构建；本地入口不执行本地测试集，不进行效果调参或无限重试。
- [ ] 默认测试不付费；实际预检记录命令、依赖、模型、用量和身份。凭据或服务不可用时必须写明未完成项，不能将实现入口视为真实预检完成。
- [ ] 不宣称真实 provider 不重复计费，不发起代码 push、PR、部署或课程提交；同步准备、启动、失败诊断和恢复说明。
