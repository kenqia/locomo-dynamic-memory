## What to build

使用者在评测页面及机器可读结果中同时查看成功样本 QA、相对计划范围的运行成功率、基线运行得分、分组证据覆盖和调用成本，能辨别部分结果、运行失败与缺少标注。

父规格用户故事：US37、US38、US39、US40、US41、US42、US43、US44、US45、US46。

## Acceptance criteria

- [ ] 保留已有官方 LoCoMo 类别计分规则，包括类别 1 子答案、2/4 词干 F1、3 分号及 5 拒答规则；类别 5 缺普通答案时仍按适用规则计分，不把 adversarial_answer 当普通 gold。
- [ ] 并列报告成功且可计分项的 QA 均值及计分覆盖率、成功数相对全部计划项的运行成功率、失败/待执行/未知数，不仅展示成功样本平均值。
- [ ] 补充运行得分按具有适用参考计分规则的全部计划项计算，执行失败贡献零分；无 gold、未知类别等本来不可计分项排除并单列，重试不重复占分母。
- [ ] 待执行或结果未确认项不提前判零，未完整执行时最终补充得分明确未完成；终态失败与未计分标注缺失不能混同。
- [ ] 按策略、对话和 QA 类别展示结果和分母，总体逐题汇总，分对话均值另列；保留逐项原始分数和可导出的机器可读记录。
- [ ] 初始、扩展、有效及实际回答上下文的来源覆盖分阶段展示，坏引用与空证据不可计分；Full Text 输入覆盖不冒称检索能力，Memory K 与 Source Turn 去重口径分明。
- [ ] 无独立动态标签时显示未评；模型自标、来源命中与课程真值不能混同，不把补充运行得分标成教师评分。
- [ ] 构建成本与查询成本分开，保留可追溯的全部尝试用量；缺失或未知用量单列，不能宣称完整费用或仅统计成功尝试。尝试数据沿用已完成的进度与恢复票契约。
- [ ] 公开 API 测试混合成功、失败、缺 gold、未知类别、坏 evidence、类别 5 和部分执行；现有页面展示不因零成功、空分组或未完成状态崩溃。
- [ ] 同步计分、分母和结果读取说明；本票不执行真实模型评测，也不要求新的浏览器验收范围。
