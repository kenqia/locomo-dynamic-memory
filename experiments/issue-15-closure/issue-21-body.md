## What to build

使用者通过已验证的本地运行流程执行四个开发对话的全部四策略比较，得到可恢复、可复查的逐项结果、汇总报告和证据化失败案例，作为后续是否优化或制作动态标注集的依据。

## Acceptance criteria

- [ ] 在真实预检通过后，完整构建并固定 conv-26、conv-30、conv-41、conv-42，使用统一模型及生成参数运行全部 757 道 QA、3,028 个组合。
- [ ] 所有计划项具有明确状态，无静默丢弃；预检项仅在完整身份匹配且可审查复用时复用，不手工抄分拼成全量结果。
- [ ] 通过本地入口启动、读取与显式恢复；已提交成功项不重跑，失败或未知项的重试有选择和尝试历史。记录首次失败与最终采用结果，不通过多次尝试挑分。
- [ ] 产出逐项机器可读记录及按策略、对话、类别的 QA、运行成功率、基线运行得分和各阶段覆盖报告，并展示所有分母与未计分原因。
- [ ] 分列构建与查询开销、耗时、调用、重试和 provider 已报告 tokens，缺用量单列，不隐去 Full Text 与 RAG 的不同上下文量或 Vector 额外调用。
- [ ] 失败案例回查原始来源、Memory、初始检索、扩展、有效证据和引用，只有证据足够才归因；无法定位时明确未确定，不从来源命中直接推断语义正确。
- [ ] 保留原始数据/划分/构建/实现/模型/Prompt/schema/配置身份、精确命令和执行日期，其他人员可以读取已有结果而不触发模型。
- [ ] 动态准确率显示未评，不制作未核查伪真值；不查看 conv-43、conv-44 模型成绩，不开展学生模型训练或效果优化，不宣称教师最终评分。
- [ ] 若真实服务、凭据或中断导致无法完成，报告准确已完成范围和外部阻塞；不得把受控结果、跳过或部分运行声明为全量完成。
- [ ] 本票交付为实验产物与分析，不代替非作者复核、合并验证或课程验收；按真实进度更新关联任务，本次不关闭或修改父规格。
