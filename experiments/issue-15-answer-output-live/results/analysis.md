## 可以确认的改善

原有 16 项执行失败在本轮同题复验中都成功返回，没有最终失败或未知外部结果。
98 次真实请求中有一次解析因输出上限截断并返回不完整 JSON，有限重试后成功；其余 97 次正常通过。
没有通过放松来源、冲突、人物或未来日期校验来消除失败，也没有执行新的关系判断或抽取。

可回答 8 题 F1 的变化为 Dynamic 0.154 → 0.334、Raw Fallback 0.039 → 0.340、
Hybrid 0.020 → 0.388、Full Text 0.179 → 0.376。主答案平均词数分别从
57.1 → 19.2、92.8 → 16.9、72.0 → 19.1、82.0 → 23.3。
长度统计只包括各轮成功产出答案的样本，样本成功集合有变化，不能把全部分数提升归因于压缩。

本轮三种 RAG 在每道题上的初始与扩展候选集合都相同；与前轮相比，每种策略的
10 道题初始和扩展候选集合也全部相同。底层来源、Memory、关系、投影、索引和构建状态
在新快照及原库中均保持原摘要，能够排除本轮重建记忆库或换题带来的成绩差异。
请求模型名及实际返回名均为 `deepseek-flash`，服务别名不保证权重固定，且未重复采样。

Full Text 在 10 道题上均完整送达 419 轮、获得 HTTP 200、通过答案校验；没有证据截断或上下文超限。
Hybrid 的本轮 F1 高于 Dynamic，不能把“Dynamic 修复了执行失败”解释成“解析必定优于跳过解析”。
两者共享构建时关系与历史扩展，这个对照也不能单独估计构建关系判断的贡献。

## 仍未达到的部分

### Dynamic 和 Hybrid 拒答短语未完全统一

QA 153 问 Melanie 的夏季领养计划，两者都指出没有具体夏季计划，只保留她在十月的
不确定领养想法。没有把 Caroline 的领养计划赋给 Melanie，但主答案未包含官方评分器识别的
`no information available` 或 `not mentioned`，因此仍为 0。QA 157 两者都回答
`No information available.`，获得 1 分。Raw Fallback 与 Full Text 两题都匹配成功。

本轮没有改写评分规则，也没有事后将模型答案替换成固定短语。
`answer.explanation` 已独立保存，但“尽量简短”的 Prompt 仍未稳定产出最短答案。
例如 QA 0 的主答案仍包含日期推导说明，而非仅 `7 May 2023.`。

### Raw Fallback 的 QA 3 仍漏答，不能只归因于回退覆盖

QA 3 的三个其他策略均回答研究领养机构；Raw Fallback 返回 `No information available.`。
其扩展候选中确有 `Caroline is researching adoption agencies.`，但首次解析的
`resolution_input_budget=12000` 将该 Memory 所在证据组省略。
首次解析没有建立该事实的支持，因此新的“保留已支持证据”规则没有这一支持可供保留。
补查命中的 D17:7、D17:8 是 Caroline 建议 Melanie 研究领养，以及 Melanie 接受建议，
不是 Caroline 自己的研究主题，无法补回原事实。

这次有证据表明问题落在解析输入的证据打包与补查命中，不能声称只是模型无理由推翻了初判。
扩大检索框架或增加关系图并非本轮必要动作；后续可先检查固定预算内证据组的交付优先级。

### 活动题仍有覆盖缺口

QA 15 中 Raw Fallback 初次解析为 sufficient，未触发原文补查。
最终回答包含跑步、阅读、小提琴、绘画和陶艺，未补齐标准答案中的露营与游泳。
Dynamic、Hybrid 也没有补齐游泳，只有 Full Text 包含全部这四类活动。
这说明执行成功与整体 sufficient 不等于复合活动枚举已穷尽，现有覆盖判定仍可能漏触发补查。
