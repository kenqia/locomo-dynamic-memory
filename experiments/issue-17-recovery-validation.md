## 实现与接口

创建评测默认异步，先保存 Run 身份及所有逻辑计划项，再启动本地单工作线程。每项成功或失败独立事务提交；读取完整记录返回 `items`、历史 `attempts`、当前采用的 `results`、部分汇总和状态计数。`/progress` 只返回轻量状态计数。页面立即显示 Run ID，提供刷新、显式恢复和两类重试选项。

恢复固定原始输入、计划、题目顺序、来源校验、划分、策略、完整构建及其索引 Embedding 身份、配置、Prompt/schema、计分、运行依赖和实现身份。成功项不重跑，失败和未知项分别要求 `retry_failed` 和 `retry_unknown`。正常关闭等待当前有限调用退出后才释放后端所有权；进程崩溃后的执行中项标为结果未知，不自动执行。
