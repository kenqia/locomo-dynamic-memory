# 答辩 Q&A（基于证据；数字见 METRIC_LEDGER）

1. **Dynamic F1 更高，为什么不用它？**
点估计 +0.006545，但 95% 配对区间 [−0.020133, +0.034035] 跨零，60 题提升、56 题退化，差异无法与抽样波动区分；同时估算费用约 7.90×、中位延迟约 3.51×。在质量差异不可分辨时选择更便宜、更稳定的 Hybrid，Dynamic 保留为显式选项。[M01–M03, M07, M09]

2. **这是否说明 Dynamic 无效？**
不能这样说。我们的结论是"本实验未能提供充分证据证明稳定优势"。留出集只有 2 段对话，点估计为正；结论只针对 E25 的设定。

3. **为什么只用 2 段对话做测试？统计上够吗？**
LoCoMo 共 10 段，4 段为课程开发集；团队在开发前选定 conv-43/44 作留出集。bootstrap 按题重采样，只描述这两段对话内的题目不确定性，不支持对话级泛化，也不代表教师隐藏评分集。这是主要局限之一。

4. **7.9 倍是实际花的钱吗？**
不是。它是按已报 usage 和执行当时官方价格中的 cache-miss 峰价计算的估算比例；账户账单没有读取；18 次 usage 缺失的请求另列预约 USD 0.9522705。[M07, M15]

5. **Dynamic 为什么这么贵？**
Resolve 要把全部候选（最多 60 条 Memory）交给模型判断有效性，约占 Dynamic 估算费用的 95%；按全部尝试已报输入 token ÷ 成功项计，Dynamic 约 51,849，Hybrid 约 6,604。[M08, M16]

6. **成功率 389 vs 394 说明 Dynamic 更不稳定吗？**
只能部分说明。17 个失败中 9 个是供应商余额不足（HTTP 402），属于运行环境；8 个是 invalid_output。失败全部记 0 分，没有补跑。[M05–M06]

7. **你们的 Recall 是事实召回率吗？**
不是。它是"标注 Source Turn 被前 K 条 Memory 覆盖的比例"，是来源覆盖代理；不衡量回答是否正确，也不衡量原子事实是否被抽取。

8. **107 道题丢了正确证据，是不是解析模型删错了？**
107 是"解析后至少一个标注来源被排除"的题数，不是错误删除数。标注来源不一定是唯一必要证据，如 conv-43:qa:135 问 Tim、标注来源谈 John。20 案人工语义核查尚未完成。[M23]

9. **为什么图上 expanded 和 initial 一样，历史扩展没用吗？**
在固定 K=10 的口径下，扩展加入的 Memory 排在初始 20 条之后，不改变前 10 条覆盖。在成功子集、不限 K 的口径下，扩展把覆盖从 0.745732 提到 0.787377；两种口径不能直接比较。[M20b, M25]

10. **怎么保证没有用测试集调参？**
E25 的配置在读取任何留出问题的类别、答案或证据之前锁定并经非作者复核；生成冻结（SHA `3cab5d1b…`）并经根审计与非作者终态审计后才评分；之后没有改参数。E25 曝光之后的实验一律称"回归"。

11. **11-09 那次回归 F1 下降了，是不是修复反而变差？**
那是 12 道已曝光题上的小样本回归，普通 10 题 0.517381 → 0.456314，区间 [−0.313876, +0.233333] 很宽，不能证明变好或变差；它不是新的留出结果，E25 不变。[M36]

12. **E12 里 Dynamic 成功子集高 0.026，为什么不算结果？**
那是开发集、旧配置，而且只在双方都成功的 705 对上计算；Dynamic 有 48 次失败，按完整分母（aggregate-derived 交叉核对）为 0.515133，低于 Hybrid 的 0.521886。它促成了"坚持完整分母"的方法，不作为最终结果。[M30–M32]

13. **SUPERSEDE、CONFLICT 判断准不准？**
没有测量。已有 60 个关系单位的 AI 诊断不覆盖 SUPERSEDE 和 CONFLICT，不能外推四标签准确率。这是未来工作。

14. **演示视频里的问答是真实调用模型吗？**
不是。演示使用 OFFLINE SYNTHETIC REPLAY：合成数据、预先保存的 Trace，0 次模型调用，画面全程标注。系统的真实调用能力由冻结运行记录支持：E25 共 2,112 次真实物理请求，记录在 `level-e-runtime-terminal-v1.json`；11-09 回归另有 62 次请求。

15. **Graph / 压缩 / Sidecar 都没用，为什么还做？**
它们是针对多跳关系、成本和时间推理提出的假设。实现与评估后没有得到问答收益（Sidecar 在两个真实构建上 0/68 信息性正确），所以默认关闭，作为负面结果报告，代码保留便于复查。

16. **为什么默认策略在 README 和内部工具里不一样？**
公共 `POST /queries` 与页面默认 Hybrid；内部历史 QueryRequest 默认 Dynamic，仅用于复现旧实验工具，不影响公共入口。见 `docs/release/DEFAULTS_AND_ROLLBACK.md`。

17. **为什么交付包里没有 LoCoMo 原始数据和完整 Memory 导出？**
上游许可为 CC-BY-NC-4.0，课程渠道是否允许再分发未确认；六份真实导出含人物原文。公开包只提供 Schema、清单、哈希和合成演示数据。

18. **如何复现？**
`uv sync --locked --python 3.12`，`uv run --locked python tools/team_v2/demo.py replay` 即可无密钥运行演示；E25 冻结工件与图表生成脚本在仓库中，图表可从冻结 JSON 只读重算。

19. **团队分工怎么体现？**
按团队工作流与 M5 成员评审记录整理职责草稿，最终表述由全体成员确认；不按提交数推断工作量。

20. **AI 在项目里做了什么？**
AI 代理参与实现、实验执行、数值审计和文稿初稿；AI 审阅与非作者成员复核分开记录，AI 结论不替代成员复核。
