### 00:00–00:25 项目介绍（标题卡 → 终端）

画面：标题卡 5 s（项目名、第三组在阴雨天游泳、M5 Final）；切到终端，输入启动命令并回车。

> 大家好，我们是第三组"在阴雨天游泳"。我们的项目是 LoCoMo Dynamic Memory：在长期、多会话的对话里，系统把对话整理成带来源和时间的记忆，回答问题时给出可以回查原文的引用。
> 接下来是真实的 Web 界面操作。本段演示使用离线合成回放：不调用模型，也不使用任何密钥。

### 00:25–00:55 打开 Console 与 Overview

操作：浏览器打开 `127.0.0.1:18501` → 停在 Overview → 鼠标依次指向顶部状态标签"合成回放 / 对话 / 当前版本" → 展开"数据与版本"，展示 Build 身份与指纹 → 收起。

> 这是我们的 Research Console。顶部标明当前是合成回放、所选对话和构建版本。
> 每次查询都固定在一个完整的构建版本上，Memory、关系、索引都来自同一版本，不会混用新旧数据。

### 00:55–01:35 浏览 Memory 与关系

操作：点击"Memory" → 在列表中滚动 → 依次点击 "Alex lives in Paris." 与 "Alex lives in Rome."（fixture 实际文本），再点 "Alex plans to visit Tokyo."（计划）与 "Alex does not own a car."（否定） → 停在"这条记忆的关系与冲突" → 展开"评审详情 · Memory 原始字段"，指向 reported 时间与 event 时间两个字段。

> 系统把对话拆成一条条原子事实。这里 Alex 早先住在巴黎，后来搬到罗马。
> 新的记录不会删除旧的记录：两者之间建立"替代"关系，当前状态更新为罗马，而巴黎这条历史仍然保留，用来回答历史日期的问题。
> 每条记忆分开记录"什么时候说的"和"事情什么时候发生"，计划和否定也单独标注。

### 01:35–02:05 查看 Source Turn

操作：在同一条 Memory 下点击来源 1 → 原文自动显示 → 点击来源 2 → 再切回来源 1（展示切换一致）→ 展开"核对来源身份"。

> 点击来源，就能看到这条记忆对应的原始对话轮次。来源由数据集、对话和轮次编号共同确定。
> 不过，引用编号合法并不代表内容一定支持回答，所以我们在实验里又单独做了来源审阅。

### 02:05–03:15 Query：回答、引用与 Trace

操作（每个案例约 15 s）：
1. 点击"Query" → 选择"当前事实"→"载入冻结案例" → 指向回答 "Alex lives in Rome." 与引用 D2:1。
2. 切换"历史日期" → 回答 "Alex lives in Paris."。
3. 切换"证据冲突"→ 状态 CONFLICT，两条来源都显示。
4. 切换"证据不足"→ INSUFFICIENT。
5. 展开"评审详情 · 阶段 Trace"→ 依次点击 initial / expanded / effective/delivered / answer/citations。
6. 切换"预算失败"→ 展开"阶段错误、耗时与预算"。

> 同一个问题"Alex 住在哪"，问现在，回答罗马；指定 2023 年 5 月，回答巴黎。
> Sam 的出生年份有两条互相矛盾的说法，系统不擅自选一个，而是标记为冲突，并保留双方来源。
> 护照号码对话里根本没有提到，系统回答证据不足，而不是编造。
> 展开 Trace，可以看到证据经过的四个阶段：初始检索、历史扩展、有效证据，以及最终交付给回答的引用。我们后面的错误分析就是逐阶段比较这些集合。
> 最后这个案例是预算失败。失败会被完整记录，不会被当成"没有证据"。

### 03:15–03:50 实验比较：Hybrid 与 Dynamic

操作：点击"Experiments" → 指向"原 Run 计划组合 3028" → 在"成本策略"中切换 Hybrid / Dynamic → 停 3 s。切到报告图 F7（屏幕显示 PDF 或图片，**左上角标"报告图表 · E25 留出实验"**），停 10 s。

> 实验页展示的是我们早期在开发对话上的 757 题四策略历史结果，成功子集和完整分母分开显示，费用是历史价格估算，不是实际扣费。
> 最终结论来自独立留出实验：conv-43 和 conv-44 两段对话，共 400 题，两种策略各跑一次，在读取标准答案之前就锁定了配置。
> 在事实类问题上，Hybrid 的 F1 是 0.403，Dynamic 是 0.409，差值的 95% 区间跨过零，也就是没有证据表明 Dynamic 稳定更好。
> 而 Dynamic 按已报用量估算的费用约是 Hybrid 的 7.9 倍，中位延迟约 3.5 倍。

### 03:50–04:30 总结

画面：回到 Overview；最后 5 s 显示结尾卡（GitHub 地址、版本 SHA、"OFFLINE SYNTHETIC REPLAY；无模型调用"）。
